## Overview

Crunchy Piper is a fun, high-energy brand packaging design project featuring custom mascot illustrations and vibrant color theory.

## Key Features

- **Mascot Design**: Created a custom character mascot to represent the brand personality.
- **Packaging Layout**: Designed eye-catching snack pouches and print layouts.
- **Color Identity**: Combined high-contrast color palettes for maximum shelf visibility.
